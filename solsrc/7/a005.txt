=== 7.9.13
The key's reading is that all non-zero entries lie within **a** rows, and also within **b** columns. A set of non-zero entries with no two in the same row or column uses a different row for each entry, so it has at most $a$ entries. It also uses a different column for each, so at most $b$. Hence at most $\min(a,b)$. **Option D** (the official key).

(If instead the a rows **together with** the b columns cover the entries, the bound becomes $a+b$. That's König's theorem: the maximum matching equals the minimum line cover.)

=== 7.10.1
The coefficient matrix is $\begin{pmatrix}1&1/2\\3&1\end{pmatrix}$. Its Frobenius norm is $\sqrt{11.25}\approx3.35$, which isn't an option, so the question means the norm of an **iteration matrix**.

Reorder the equations to make them closer to diagonally dominant, solving the second one for x and the first one for y:

- $x = (10 - y)/3$
- $y = 18 - 2x$

The Jacobi iteration matrix is then $\begin{pmatrix}0&-1/3\\-2&0\end{pmatrix}$, and its Frobenius norm is
$$\sqrt{\tfrac19 + 4}\approx2.03\approx\mathbf{2.0}$$

=== 7.10.2
Gauss–Seidel's behaviour depends on how the equations are ordered:

- **In the given order** ($x = 9 - y/2$, $y = 10 - 3x$), the iteration matrix has spectral radius 1.5, so the method **diverges**.
- **Swapped** ($x = (10-y)/3$, $y = 18 - 2x$), each sweep multiplies the error by $\tfrac23$, so the method **converges** to the exact solution $x = -8$, $y = 34$.

The official key is **A (it will converge)**, which assumes the convergent ordering. In an exam, note that the method converges only after rearranging the equations.

=== 7.11.2

For a symmetric positive semi-definite matrix, the singular values equal the eigenvalues. So they're **0 or 1** (A ✔, B ✔).

A has rank 5 < 10, so $\det A = 0$ and A isn't invertible (C ✘, D ✘).

=== 7.12.1
The matrix norm induced by $\|\cdot\|_\infty$ is the **maximum absolute row sum**:

- row 1: 2 + 5 + 9 = 16
- row 2: 4 + 6 + 5 = 15
- row 3: 8 + 2 + 3 = 13

So $\|A\|_\infty = \mathbf{16}$.

**Why the condition number is expensive.** $\kappa(A) = \|A\|\,\|A^{-1}\|$ needs $\|A^{-1}\|$. Getting that essentially requires computing (or factoring) $A^{-1}$, which costs $O(n^3)$, compared with $O(n^2)$ for $\|A\|_\infty$.
