=== 7.17.9
The coefficient matrix is circulant. A non-trivial solution needs
$$\det = 3pqr - (p^3 + q^3 + r^3) = -(p+q+r)(p^2+q^2+r^2-pq-qr-rp) = 0$$
The second factor equals $\tfrac12[(p-q)^2 + (q-r)^2 + (r-p)^2]$, which is 0 only when $p = q = r$.

So **$p+q+r = 0$ or $p = q = r$**. **Option C**.

=== 7.17.13

- **B ✘.** The null space might be bigger than $m - n$, so $m - n$ vectors may not span it.
- **C ✘.** Not guaranteed in general.
- **D ✘.** Not guaranteed in general.

=== 7.17.14
$\det = 1 - k^2$.

- For $k\ne\pm1$: exactly one solution.
- **$k = 1$:** $x + y = 1$ and $x + y = -1$, so **no solution**.
- **$k = -1$:** $x - y = 1$ and $-x + y = -1$, the same equation, so **infinitely many** solutions.

So exactly one value of $k$ gives no solution (A ✔), and exactly one gives infinitely many (D ✔).

**A and D**.

=== 7.18.4

=== 7.18.5
A is the **Gram matrix** of the $x_i$, i.e. $A = X^TX$. Since the $x_i$ are independent, X is invertible, so $\det A = (\det X)^2 > 0$.

A is invertible (A ✔). It's positive definite, so all singular values are positive (B ✘), $\det A\ne0$ (C ✘), and $z^TAz = \|Xz\|^2 > 0$ for $z\ne0$ (D ✘). **Option A**.
=== 7.18.6

- **C ✔ and D ✔.** Projecting twice is the same as projecting once: $M^2 = M$, and so $M^3 = M$.
- The null space is $U^\perp$, with dimension $3 - \dim U$:
  - U 1-dimensional gives a null space of dimension 2 (A ✘).
  - U 2-dimensional gives a null space of dimension 1 (B ✔).
