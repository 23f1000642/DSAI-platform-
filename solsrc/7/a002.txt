Compare the rows of B with the rows of A ($R_1..R_4$):

- B's row 3 is (1,2,3,4), which is $R_1$.

=== 7.4.10
This is a tridiagonal matrix with 3 on the diagonal and 1 on the off-diagonals. Expanding along the first row gives
$$D_n = 3D_{n-1} - D_{n-2}, \qquad D_1 = 3,\; D_2 = 8$$
The characteristic roots are $r = \frac{3\pm\sqrt5}{2}$, so $D_n = a\,r_1^{\,n-1} + b\,r_2^{\,n-1}$.

From $D_1 = 3$ and $D_2 = 8$, the constants work out to $a = \frac{3\sqrt5+7}{2\sqrt5}$ and $b = \frac{3\sqrt5-7}{2\sqrt5}$.

Check $n = 1$: $a + b = \frac{6\sqrt5}{2\sqrt5} = 3$ ✔. **Option D**.
=== 7.4.11
Expand along row 3, which has a single 1, in column 4. Its cofactor sign is $(-1)^{3+4} = -1$:
$$-\begin{vmatrix}0&1&0\\-1&1&1\\1&-2&0\end{vmatrix}$$
Expand the 3×3 along column 3, where only the middle entry (1) is non-zero, with sign $(-1)^{2+3} = -1$:
$$-1\cdot\begin{vmatrix}0&1\\1&-2\end{vmatrix} = -1\cdot(0 - 1) = 1$$
So the determinant is $-1\cdot1 = \mathbf{-1}$. **Option A**.
