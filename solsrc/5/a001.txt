=== 5.1.1
f must be continuous and differentiable at both $x = 1$ and $x = 2$.

**At $x = 1$:**

- continuity: $1 = a + b + c$
- derivative: $2 = 2a + b$

**At $x = 2$:**

- continuity: $4a + 2b + c = 2 + d$
- derivative: $4a + b = 1$

From the two derivative equations, $2a = -1$, so $a = -\tfrac12$ and $b = 3$. Then:

- $c = 1 - a - b = 1 + \tfrac12 - 3 = -\tfrac32$
- $d = 4a + 2b + c - 2 = -2 + 6 - \tfrac32 - 2 = \tfrac12$

**$a = -\tfrac12$, $b = 3$, $c = -\tfrac32$, $d = \tfrac12$**.

=== 5.2.2
Ratio test, with $a_m = \frac{(3m)!}{(m!)^3}x^{3m}$:
$$\left|\frac{a_{m+1}}{a_m}\right| = \frac{(3m+3)(3m+2)(3m+1)}{(m+1)^3}|x|^3 \to 27|x|^3$$
It converges when $27|x|^3 < 1$, i.e. $|x| < \tfrac13$. The radius of convergence is **1/3**.
