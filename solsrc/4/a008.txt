=== 4.10.31
$\lnot((p\Rightarrow q)\land(\lnot r\lor\lnot s))$ is true when $(p\Rightarrow q)$ is false **or** $(\lnot r\lor\lnot s)$ is false.

- **$\lnot r\lor\lnot s$ false** would need x to be both a perfect square and prime. That's impossible.
- **$p\Rightarrow q$ false** needs $x\in\{8,9,10,11,12\}$ and x **not** composite. The only such x is **11**.

**x = 11**.

=== 4.10.34

The expression is true exactly when q is true: **always true when q is TRUE**. **Option D**.
