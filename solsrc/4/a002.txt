=== 4.4.2
The four conjuncts say that R is:

- **serial:** every $x$ has some $y$ with $R(x,y)$
- **asymmetric**
- **transitive**
- **irreflexive**

So R is a **strict partial order with no maximal element**.

**Finite models? No.** Start at any $x_0$. Seriality gives a chain $x_0 R x_1 R x_2 \dots$. By transitivity, $x_i R x_j$ for all $i < j$. If two of the elements were equal, $x_i = x_j$ with $i < j$, we'd get $x_i R x_i$, which contradicts irreflexivity. So the chain has infinitely many distinct elements, and there's **no finite model**.

**Satisfiable? Yes.** A countable model: the domain is $\mathbb N = \{0, 1, 2, \dots\}$ with $R(x,y) \iff x < y$. Check each condition:

- serial: $x < x+1$
- asymmetric: $x < y \Rightarrow \neg(y < x)$
- transitive
- irreflexive
=== 4.4.3
**A is valid.** If $P(x)$ holds for all $x$, then so does $P(x)\vee Q(x)$, and similarly for $Q$.

The others fail:

- **B:** $P$ might hold for one element and $Q$ for another, but not both on the same one.
- **C:** half the domain may satisfy $P$ and the other half $Q$.
- **D** isn't valid either.

**Option A**.
=== 4.4.4
**D:** if $\forall x(\alpha\Rightarrow\beta)$ and $\forall x\,\alpha$, then for each $x$ both $\alpha$ and $\alpha\Rightarrow\beta$ hold, so $\beta$ holds. So $\forall x\,\beta$. This is **valid**.

- A is the converse direction, which isn't valid.
- B fails when $\beta$ is false everywhere.
- C isn't valid.

**Option D**.
=== 4.4.5
Inside the brackets: $\forall y[Q_{xy}\Leftrightarrow\neg Q_{yy}]$. Take $y = x$: this gives $Q_{xx}\Leftrightarrow\neg Q_{xx}$, which is always **false**.

So the antecedent becomes $\forall x[P_x\Leftrightarrow\text{false}] = \forall x\,\neg P_x$, and $\alpha$ is
$$\forall x\neg P_x\Rightarrow\forall x\neg P_x$$
That's a **tautology**, true in **every** interpretation. **Both I₁ and I₂ satisfy α**, **option D**.

=== 4.4.10
The intended reading is that **for every** fsa $x$, there exists a pda $y$ equivalent to it:
$$\forall x\,(fsa(x)\to\exists y\,(pda(y)\wedge equivalent(x,y)))$$
- A's $\forall x\,fsa(x)$ claims everything is an fsa.
- C and D use ∧ where → is needed.
- B, after simplification, says something different again.

None of the options is exactly right, so the key gave **marks to all**.
