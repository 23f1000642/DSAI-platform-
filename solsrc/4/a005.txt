=== 4.7.1
Let R = "it rains" and P = "the match is played". The premise is $R\to\lnot P$.

- **I1:** the match was played ($P$). By **modus tollens**, $\lnot\lnot P$ gives $\lnot R$: there was no rain. This is valid.
- **I2:** it did not rain ($\lnot R$), and the conclusion is P. That's **denying the antecedent**, a fallacy: the match might be cancelled for some other reason.

=== 4.7.3
Let T = "the speaker is truthful" and H = "the toss is head". The speaker claims $H\leftrightarrow T$.

- **Truth-teller (T true):** the claim is true, so $H\leftrightarrow\text{true}$, which means H.
- **Liar (T false):** the claim is false, so $\lnot(H\leftrightarrow\text{false}) = \lnot\lnot H$, which means H.

Either way, **the result is head**. **Option A**.

- (iii) "Today is Sunday" is declarative. ✔

- (iv) is a command. ✘

=== 4.7.8
a: C
- **(A)** $P\to(P\land Q) \equiv P\to Q$, so the formula is $X\to X$. **Tautology.**
- **(B)** $(P\to Q)\to Q \equiv \lnot(\lnot P\lor Q)\lor Q \equiv (P\land\lnot Q)\lor Q \equiv P\lor Q$, so again $X\to X$. **Tautology.**
- **(C)** $P\lor\lnot P$ is always true, so it reduces to $Q\to R$. Not a tautology.
- **(D)** $P\land\lnot P$ is always false, so it reduces to $\lnot Q\to\lnot R$. Not a tautology.

**(A) and (B) only** is choice (3), which is **option C** here.
=== 4.7.9
$$(p\to q)\land(\lnot q\lor p) = (p\to q)\land(q\to p) = p\leftrightarrow q$$

None of the options equals $p\leftrightarrow q$:

- A gives $q\to p$ only.
- B gives $p\to q$ only.
- C and D, $(p\to q)\lor(q\to p)$, are **tautologies**, so they're true even when p and q differ.

This item has no official answer. The correct simplification is $p\leftrightarrow q$.
