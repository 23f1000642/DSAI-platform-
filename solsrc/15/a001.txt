=== 15.1.1
`A.extend(B)` appends each element of B, giving [1, 2, 3, 4, 5, 6]. (`append` would add the whole list as one element: [1, 2, 3, [4, 5, 6]].) **Option A**.
=== 15.2.1
**First pass**, "this" in A:

- A − B = {this}
- B − C = {that}
- C − A = {other}

Then "that" is in B:

- A = C | A = {other, this}
- B = A | B = {this, that}
- C = B | C = {that, other}

**Second pass**, "this" in A:

- A − B = {other}
- B − C = {this}
- C − A = {that}

"that" isn't in B, so nothing more happens. "other" isn't in C either, so the loop stops.

The final sets are A = {other}, B = {this}, C = {that}. Only **B** contains "this". **Option B**.
=== 15.2.2
f(a, b) computes $a\times b$ using doubling:

| call | result |
|---|---|
| f(15, 10) | 2·f(7, 10) |
| f(7, 10) | 2·f(3, 10) |
| f(3, 10) | 2·f(1, 10) |
| f(1, 10) | 2·f(0, 10) = 2·10 = 20 |

Working back up: f(3) = 40, f(7) = 80, f(15) = **160**.

(It isn't 15 × 10, because an odd a returns 2·f((a−1)/2), dropping the extra b.)
