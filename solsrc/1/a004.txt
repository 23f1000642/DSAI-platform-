=== 1.7.6
- **I:** $(n+k)^m = n^m + \binom m1 k n^{m-1} + \dots$. The leading term is $n^m$, so this is $\Theta(n^m)$. ✔
- **II:** $2^{n+1} = 2\cdot 2^n = O(2^n)$. ✔
- **III:** $2^{2n+1} = 2\cdot 4^n$, and $4^n/2^n = 2^n \to\infty$. So it is **not** $O(2^n)$. ✘

I and II, **option A**.
=== 1.7.7
A comparison sort is a binary decision tree with at least $n!$ leaves, one for each possible ordering. Its height is at least
$$\lg(n!) = \Theta(n\log n)$$
by Stirling's approximation. Merge sort achieves this bound, so it's tight: **$n\log n$**, **option C**.
=== 1.7.8
$T(n) = 2T(n/2) + n$ is the merge-sort recurrence, so $T(n) = \Theta(n\log n)$.

- A: $O(n^2)$ is a valid (loose) upper bound. ✔
- B, D: ✔
- C: $\Omega(n^2)$ would need $n\log n$ to grow at least as fast as $n^2$, which it doesn't. ✘

The false statement is **C**.
=== 1.7.9
Compare the functions as powers of 2:

- $h(n) = n^{\log n} = 2^{\log^2 n}$
- $f(n) = 2^n$
- $g(n) = n! \approx 2^{n\log n}$

Since $\log^2 n < n < n\log n$ for large $n$: $h \ll f \ll g$.

So $h = O(f)$ and $g = \Omega(f)$, **option D**.

=== 1.7.11
The average over all inputs of size $n$ can never exceed the maximum over those inputs. So $A(n) \le W(n)$ for every $n$, i.e. **$A(n) = O(W(n))$** always holds.

The others can fail. For quicksort, $A = n\log n$ and $W = n^2$, so A and B fail. For linear search, $A = W = \Theta(n)$, so D fails. **Option C**.
=== 1.7.12

- I: $\Theta(n^4)$ is correct.
- II: $\Theta(n^5)$ is wrong, because it isn't a tight bound.
- III: $O(n^5)$ is a valid upper bound.
- IV: $\Omega(n^3)$ is a valid lower bound.

=== 1.7.13

=== 1.7.18

=== 1.7.19
The characteristic equation is $r^2 - 5r + 6 = 0$, so $r = 2, 3$. That gives $T(n) = a\,2^n + b\,3^n$.

- $T(0) = a + b = 1$
- $T(1) = 2a + 3b = 2$

Subtracting twice the first from the second gives $b = 0$, so $a = 1$.

Therefore $T(n) = 2^n$, so $T(n) = \Theta(2^n)$, **option A**.
=== 1.7.20
From the given facts, $g = O(h)$ and $h = O(g)$, so $g = \Theta(h)$. Also $f = O(g)$ but $g \ne O(f)$, so $f$ grows strictly slower.

- A: $f + g = O(g) = O(h) = O(2h)$. True.
- B: $f = O(g) = O(h)$. True.
- C: if $h = O(f)$, then $g = O(h) = O(f)$, which contradicts the given. So $h \ne O(f)$. True.
- D: since $f = O(g)$, multiplying by $h$ gives $fh = O(gh)$. So "$fh \ne O(gh)$" is **FALSE**.

**Option D**.
