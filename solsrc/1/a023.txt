=== 1.53.8
The pivot is the $(n/4)$-th smallest element, found in $O(n)$. Every split is then $(n/4,\,3n/4)$:
$$T(n) = T(n/4) + T(3n/4) + O(n) = \Theta(n\log n)$$
Each level of the recursion tree costs $O(n)$, and there are $O(\log_{4/3} n)$ levels. **Option B**.
=== 1.53.9
- **[1 2 3 4 5]** (sorted, first-element pivot) is the worst case: $4+3+2+1 = 10$ comparisons.
- **[4 1 5 3 2]**: pivot 4 takes 4 comparisons and leaves {1, 3, 2} and {5}. Sorting the 3-element part takes at most 3 more, for at most about 7 in total.

So $t_1 > t_2$, **option C**.
=== 1.53.10
A central-element pivot can still be the smallest or largest value every time. An adversarial input can arrange that at every level, so each partition peels off one element and the worst case is $O(n^2)$.

It's tight, so the tightest worst-case upper bound is **$O(n^2)$**. **Option A**.
=== 1.53.11
In the worst case, the pivot ends up at one end, leaving subproblems of size $n-1$ and $1$ (or 0). Partitioning costs $cn$:
$$T(n) = T(n-1) + T(1) + cn$$
**Option B**.
=== 1.53.12
After `partition`, the pivot is at index `left_end`: the elements before it are at most the pivot, and the elements after it are larger.

- If the pivot is the $k$-th smallest (`left_end+1 == k`), return it.
- If `left_end+1 > k`, the answer is in the left part: `kth_smallest(a, left_end, k)`.
- Otherwise it's in the right part, which starts at `a+left_end+1` and has `n-left_end-1` elements. We've skipped `left_end+1` smaller elements, so search for rank `k-left_end-1`.

**Option A**.
=== 1.53.13
The worst position for the pivot is either end, i.e. the pivot is the smallest or largest element. That's 2 of the 25 equally likely choices:
$$\frac{2}{25} = \mathbf{0.08}$$
=== 1.53.14
The array 60, 70, 80, 90, 100 is already sorted, and the last element is the pivot.

In every partition step, each element is smaller than the pivot and already on its correct side. An in-place partition that skips the trivial self-swap ($i = j$) never needs to swap anything, and each pivot is already in its final place. So the minimum number of swaps is **0**.
=== 1.53.15
The shallowest leaf is reached by always following the **smaller** fraction $\alpha$. After $d$ levels the size is $\alpha^d n$, and it becomes 1 when
$$d = \log_{1/\alpha} n = -\frac{\lg n}{\lg\alpha}$$
**Option C**. The deepest leaf, along the $1-\alpha$ side, is at depth $-\lg n/\lg(1-\alpha)$.
=== 1.54.1
Unroll the recurrence:
$$T(n) = T(1) + 2 + 3 + \dots + n = 1 + 2 + \dots + n = \frac{n(n+1)}{2}$$
So $T(n) = \frac{n(n+1)}2 = \Theta(n^2)$.
=== 1.54.2
Each step halves $n$ and adds 1. With $n = 2^k$, it takes $k$ steps to reach $T(1) = 1$:
$$T(n) = \log_2 n + 1 = \Theta(\log n)$$
=== 1.54.3
Unroll the recurrence with $n = 2^k$:
$$T(n) = \sqrt n + \sqrt{n/2} + \sqrt{n/4} + \dots + T(1) = \sqrt n\sum_{i=0}^{k-1}\left(\tfrac1{\sqrt2}\right)^i + 1$$
This is a geometric series with ratio $1/\sqrt2$:
$$T(n) = \frac{\sqrt n - 1}{1 - 1/\sqrt2} + 1 = (2+\sqrt2)(\sqrt n - 1) + 1 = \Theta(\sqrt n)$$
=== 1.54.4
Divide both sides by $n+1$:
$$\frac{T(n)}{n+1} = \frac{T(n-1)}{n} + \frac1{n+1}$$
Let $S(n) = \frac{T(n)}{n+1}$, so $S(1) = \frac12$. Then
$$S(n) = \frac12 + \sum_{k=3}^{n+1}\frac1k = H_{n+1} - 1$$
So
$$T(n) = (n+1)\left(H_{n+1} - 1\right)$$
Check: $T(2) = 3\left(\tfrac12 + \tfrac13\right) = 2.5$, and the recurrence gives $\tfrac32\cdot1 + 1 = 2.5$ ✔.

Since $H_n \approx \ln n$, **$T(n) = \Theta(n\log n)$**.
=== 1.54.5
For $n = 1$, the function returns 3.

For $n > 1$, each pass of the outer loop resets $C$, counts it up to $n-1$, then multiplies. Let $P_i$ be the value of F1 after $i$ outer iterations:
$$P_i = (n-1)\cdot P_{i-1}, \qquad P_0 = 1, \qquad F(n) = P_n$$
So the recurrence is: F(1) = 3, and for $n \ge 2$, F(n) is $(n-1)$ multiplied by itself $n$ times. The next part asks for the closed form, which is $(n-1)^n$.
=== 1.54.6
From the loops: the inner loop sets $C = n-1$, and the outer loop does this $n$ times, multiplying each time. The closed form is
$$F(n) = \begin{cases}3 & n = 1\\ (n-1)^n & n \ge 2\end{cases}$$
For example, $F(2) = 1$ and $F(3) = 2^3 = 8$.
=== 1.54.7
The pass with argument $n$ runs the `if` for $i = 1..n-1$, which is $n-1$ times, then recurses on $n-1$:
$$a_n = a_{n-1} + (n-1), \qquad a_1 = 0$$
Solving gives
$$a_n = \sum_{i=1}^{n-1} i = \frac{n(n-1)}{2}$$
