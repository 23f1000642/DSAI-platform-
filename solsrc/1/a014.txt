=== 1.32.4
Start with $a = a_0$ and $b = b_0$:

- `a := a+b` gives $a = a_0+b_0$
- `b := a-b` gives $b = a_0$
- `a := a-b` gives $a = b_0$

The values are **exchanged** without a temporary variable. **Option A**. (In practice, overflow is the only risk.)
=== 1.32.5
This is **fast exponentiation by repeated squaring**. Write $n = 2q + r$ with $r = n \bmod 2$:
$$\text{what}(x,n) = x^r\cdot\text{what}(x^2, q) = x^r\cdot(x^2)^q = x^{2q+r} = x^n$$
The base case $n = 0$ returns 1.

So it computes **$x^n$**, using $O(\log n)$ multiplications.
=== 1.32.6
The `else` attaches to the **nearest** `if` (the dangling-else rule):
```
if X > Y then
    if X < 0 then X := abs(X) else X := 2*X;
```
$X = -10$ and $Y = 20$, so $X > Y$ is false. The whole inner statement is skipped, and $X$ stays **−10**. **Option C**.
=== 1.32.7
This is Euclid's subtraction form: repeatedly subtract the smaller number from the larger. $\gcd(X,Y) = \gcd(X-Y, Y)$, so the gcd never changes, and the loop stops when $X = Y = \gcd$.

Example: (12, 8) → (4, 8) → (4, 4), so it prints 4. **Option C**.
=== 1.32.8
**A.** `GET(A,B)` satisfies the binomial recurrence: $\binom A0 = 1$, $\binom AB = 0$ when $A<B$, and $\binom AB = \binom{A-1}{B} + \binom{A-1}{B-1}$. So $\text{GET}(A,B) = \binom AB$.

$$\text{GET}(3,2) = \text{GET}(2,2) + \text{GET}(2,1) = 1 + 2 = \mathbf{3}$$

**B.** The loops visit **every** pair $(I,J)$, so each off-diagonal pair is swapped **twice**: once as $(I,J)$ and again as $(J,I)$. That restores the original matrix. Swap only the upper triangle:
```
for I := 1 to N-1 do
  for J := I+1 to N do
  begin
     TMP := A[I,J]; A[I,J] := A[J,I]; A[J,I] := TMP
  end;
```
=== 1.32.9
This is McCarthy's 91 function: for every $x \le 100$ it returns 91.

For $x = 95$:

- fun(95) = fun(fun(106)) = fun(96)
- fun(96) = fun(97) = … = fun(100) = fun(fun(111)) = fun(101) = **91**

**Option C**.
=== 1.32.10
For distinct values it returns the middle one. For example, Trial(1,2,3) → Trial(2,1,3) → Trial(2,3,1) → Trial(3,2,1) returns 2.

But consider **a = b = c**, for example (1,1,1):

- `a>=b` is true, but `c<b` is false
- so it calls Trial(a, c, b) = Trial(1,1,1) again

That recurses **forever**. Inputs like (3,1,1) also loop forever. The function doesn't correctly compute the max, the min or the middle for all inputs, so the answer is **None of the above**, **D**.
=== 1.32.11
Write $s = XY$, where $X = s[1..k]$ and $Y = s[k+1..n]$.

1. reverse(1,k) gives $X^R Y$
2. reverse(k+1,n) gives $X^R Y^R$
3. reverse(1,n) gives $(X^RY^R)^R = YX$

$YX$ is $s$ **rotated left by $k$** positions. **Option A**.
=== 1.32.12
At step $i$, $p$ is multiplied by $x/i$, so after $i$ steps $p = \frac{x^i}{i!}$. And $s$ starts at 1 and accumulates:
$$s = 1 + x + \frac{x^2}{2!} + \dots + \frac{x^{y-1}}{(y-1)!}$$
For large $y$, this is the Taylor series of **$e^x$**. **Option B**.
=== 1.32.13
$A[j]$ ends up 0 only if $j \bmod k = 0$ for **every** $k$ with $2 \le k \le \min(\text{TwoLog\_n},\, j-1)$.

- If $j-1 \le$ TwoLog_n, then $k = j-1$ is in the range, and $j \bmod (j-1) = 1 \ne 0$. So $A[j] = 1$.
- Otherwise $j$ would have to be divisible by every number $2, 3, \dots, 2\lceil\log_2 n\rceil$. Their lcm is far larger than $n$ (it grows roughly like $e^{2\log n}$), so no $j \le n$ qualifies.

Every $A[j]$ becomes 1 and nothing is printed: **{ }**, **option D**.
