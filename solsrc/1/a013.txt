=== 1.31.5
The string is **abbccddeee**, with frequencies a = 1, b = 2, c = 2, d = 2, e = 3.

Property 1 means it must be a prefix code. The minimum cost comes from Huffman merges:

1. 1 + 2 → 3
2. 2 + 2 → 4
3. 3 + 3 → 6
4. 4 + 6 → 10

Each merge adds its total to the encoded length: $3+4+6+10 = 23$.

Property 2 needs b ≤ c ≤ d in code length. Choose the merges to respect it: pair a with **d** (depth 3), make b and c a pair (depth 2), and put e at depth 2. Then b = c = 2 ≤ d = 3 ✔.

The length is $1\cdot3 + 2\cdot2 + 2\cdot2 + 2\cdot3 + 3\cdot2 = 23$. **Option B**.

=== 1.32.1
`what(s)` returns `what(s[2..n])` followed by the first character `s[1]`. So it moves the first character to the end, after reversing the rest. That's **string reversal**.

| call | result |
|---|---|
| what("HTGATE") | what("TGATE") + "H" |
| what("TGATE") | what("GATE") + "T" |
| … | … |
| what("E") | "E" |

Output: **"ETAGTH"**.
=== 1.32.2
Track $t$ after each iteration with $m = 1, 2, \dots$:

- $m=1$: $t = 1\cdot(-x/1) = -x$
- $m=2$: $t = (-x)\cdot(-x/2) = \frac{x^2}{2!}$
- $m=3$: $t = -\frac{x^3}{3!}$, and so on, so $t_m = \frac{(-x)^m}{m!}$

The `do … while (m++ < n)` loop runs for $m = 1..n$, and $y$ adds up the terms:
$$f(x) = y = \sum_{m=1}^{n}\frac{(-x)^m}{m!} = -x + \frac{x^2}{2!} - \frac{x^3}{3!} + \dots$$
This is the Taylor series of $e^{-x} - 1$, truncated after $n$ terms.
=== 1.32.3

- $M = 9$: $i = 3 = \lceil 3\rceil$
- $M = 10$: $3^2 = 9 < 10$, so $i = 4 = \lceil 3.16\rceil$
