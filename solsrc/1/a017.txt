The recursion is Pascal's rule, $\binom mn = \binom{m-1}{n} + \binom{m-1}{n-1}$. It needs base cases that return 1:

- $\binom mm = 1$, i.e. $m = n$

Every recursive path ends at one of these. So E is `(n == 0) || (m == n)`, **option C**.

=== 1.33.1

=== 1.34.1
Binary search cuts the **comparisons** for each insertion to $O(\log n)$. But the element still has to be inserted by **shifting** up to $i$ elements, which is $O(i)$ per step. Shifting dominates, so the worst case **remains $\Theta(n^2)$**. **Option A**.
=== 1.34.2
Insertion sort does exactly one shift per inversion, plus $O(n)$ for the comparisons that end each pass. Its running time is $\Theta(n + I)$, where $I$ is the number of inversions.

With $I \le n$, the time is $\Theta(n)$. **Option D**.
