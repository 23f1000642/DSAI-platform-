=== 1.7.23
The schoolbook method takes $O(n^3)$. **Strassen's algorithm** uses 7 recursive multiplications of $n/2\times n/2$ blocks instead of 8:
$$T(n) = 7T(n/2) + O(n^2) \Rightarrow T(n) = O(n^{\log_2 7}) = O(n^{2.81})$$
Among the options, this is the efficient algorithm, **option B**.
=== 1.7.24
Treat $\tan^2$ as a constant term $c$ (it doesn't depend on $n$ the way a growing function would). Then $T(n) = mT(n/2) + c$.

For $m > 1$, the Master theorem (case 1) gives $T(n) = \Theta(n^{\log_2 m})$, which matches **option B**, $O(n^{\lg m})$.

The question is ambiguous ($\tan^2$ of what?), so the official key gave **marks to all**.
=== 1.7.25
$T(n) = 2T(n/2) + \frac{n}{\lg n}$. The Master theorem doesn't apply, because $n/\lg n$ is smaller than $n$ by only a log factor. So expand the recursion tree.

At depth $i$ there are $2^i$ nodes, each costing $\frac{n/2^i}{\lg(n/2^i)}$. So level $i$ costs $\frac{n}{\lg n - i}$. Summing over $i = 0..\lg n-1$:
$$n\sum_{j=1}^{\lg n}\frac1j = n\cdot H_{\lg n} = \Theta(n\lg\lg n)$$
**Option C**.
=== 1.7.26
- $n! = 1\cdot2\cdots n \le n\cdot n\cdots n = n^n$, so $n! = O(n^n)$.
- $\log n! \le \log n^n = n\log n$, so $\log n! = O(n\log n)$. In fact it's $\Theta(n\log n)$ by Stirling.

**Option B**. (Options A and C are trivially true but aren't useful estimates. The intended answer gives each one in simpler terms.)
=== 1.7.27
The algorithm runs $M_1$ then $M_2$, one after the other. The total is $h(n) + g(n)$, and asymptotically
$$h(n)+g(n) = \Theta(\max(h(n), g(n)))$$
because $\max \le h+g \le 2\max$. The expected answer is **max**, **option B**.
=== 1.7.28
- **$E_1$:** $n^K\lg n = o(n^{K+\epsilon})$ for any $\epsilon > 0$, because $\lg n$ grows slower than $n^\epsilon$. So the sum is $\Theta(n^{K+\epsilon})$. Correct.
- **$E_2$:** $6n^2 3^n$ dominates $n^3 2^n$, because $(3/2)^n$ beats any polynomial. So the sum is $\Theta(n^2 3^n)$, which is **not** $O(n^32^n)$. Incorrect.

=== 1.7.29
For non-negative functions:
$$\max(f,g) \le f+g \le 2\max(f,g)$$
So $\Theta(f+g) = \Theta(\max(f,g))$, **option D**.

The product $f\cdot g$ is unrelated to max or min. For example, $n\cdot n = n^2$.

=== 1.9.1

A negative cycle in an unreachable part of the graph is never touched, so P is false. Q is true. **Option B**.

=== 1.11.1
Each recursive call does a constant number of arithmetic operations, like computing `mid = (lo+hi)/2` and a comparison, and halves the range. There are at most about $\log_2 n$ calls, so the total is $\Theta(\log_2 n)$, **option B**.
=== 1.11.2
Binary search needs two things: **sorted** data, so that discarding half is correct, and **random access**, so that reaching the middle element takes $O(1)$.

- Unsorted data (A, B): binary search can give wrong answers.
- A sorted linked list (D): reaching the middle takes $O(n)$ per step, so $O(n)$ in total.

Only **C**, a sorted array, gives $O(\log n)$.

=== 1.13.1
A binary tree with $n$ nodes has $2n$ child pointers. $n-1$ of them point to real nodes, because every node except the root has exactly one parent. So the number of null pointers is
$$2n - (n-1) = n+1 = 28$$
28 isn't listed, so **None of the above**, **D**.

=== 1.13.3

$$2^0 + 2^1 + \dots + 2^h = 2^{h+1}-1$$
**Option A**.
=== 1.13.4
In a full binary tree every internal node has exactly 2 children, so leaves $=$ internal nodes $+1$. With $n$ leaves there are $n-1$ internal nodes.

The total is $n + (n-1) = 2n-1$, **option C**.
