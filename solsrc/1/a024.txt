=== 1.54.10
The recurrence is Pascal's rule, but every base case returns 1. That makes $F(n,m)$ a **partial row sum** of binomial coefficients:
$$F(n,m) = \sum_{i=0}^{m}\binom ni$$
This satisfies the same recurrence and base cases.

- **(a)** $F(n,2) = 1 + n + \dfrac{n(n-1)}{2}$
- **(b)** $F(n,m) = \displaystyle\sum_{i=0}^{m}\binom ni$
- **(c)** Every call either returns 1 (a base call) or makes two more calls. So the call tree is a full binary tree whose leaves are the base calls, and the leaves add up to $F(n,m)$. A full binary tree with $L$ leaves has $2L-1$ nodes, so the number of calls is $2F(n,m) - 1 = 2\sum_{i=0}^m\binom ni - 1$.

=== 1.54.19
Look at the first bit of a valid string:

- If it starts with **1**, the rest is any valid string of length $n-1$: $x_{n-1}$ ways.
- If it starts with **0**, the next bit must be 1, and the rest is valid of length $n-2$: $x_{n-2}$ ways.

So $x_n = x_{n-1} + x_{n-2}$, **option D**. These are Fibonacci numbers.
