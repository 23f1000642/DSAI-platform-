=== 1.2.7
Check every way to cut a rod of length 7. Prices: p1=1, p2=5, p3=8, p4=9, p5=10, p6=17, p7=18.

- $7$ → 18
- $6+1$ → 17+1 = 18
- $5+2$ → 15, $\;5+1+1$ → 12
- $4+3$ → 17, $\;4+2+1$ → 15
- $3+3+1$ → 17, $\;3+2+2$ → 8+5+5 = **18**
- $2+2+2+1$ → 16, …

The maximum is $R_7 = 18$, so A is true and B is false.

It's achieved by exactly three cuttings: $\{7\}$, $\{6,1\}$ and $\{3,2,2\}$, so C is true. Since $\{3,2,2\}$ has three pieces, D is false.

Answer: **A and C**.
=== 1.2.8
Use the hint. `len1` is the run of equal values ending at $X[i]$. `len2` is the longest subarray ending at $X[i]$ with at most 2 distinct values. `first` is the previous element.

- **Branch `X[i] == second` (P):** the previous element was `first`, which differs from $X[i]$. So the run of equal values ending at $i$ is just $X[i]$ itself: **len1 = 1**. The window still has only {first, second}, so `len2++` is right.
- **Branch "new value" (Q):** the window must drop the older value. The longest valid subarray ending at $i$ is the run of `first` (length `len1`) plus $X[i]$: **len2 = len1 + 1**. Then len1 resets to 1.

P = 1, Q = len1 + 1, which is **option B**.

=== 1.2.10
Let $n = 2^m$ and $S(m) = T(2^m)$. Then $\sqrt n = 2^{m/2}$ and $\lg^2 n = m^2$:

$$S(m) = 4S(m/2) + m^2$$

By the Master theorem, $m^{\log_2 4} = m^2$, which equals $f(m)$. So $S(m) = \Theta(m^2\lg m)$.

Substituting back gives $T(n) = \Theta(\lg^2 n\,\lg\lg n)$, **option C**.
=== 1.2.11
Hill climbing has three classic failure modes:

- **Local maxima:** a peak that is higher than its neighbours but not the global best.
- **Plateaus:** a flat region where every neighbour has the same value, so there's no direction to move.
- **Ridges:** a sequence of local maxima that single moves can't climb, so the search oscillates along the ridge.

All three are shortcomings, **option D**.
=== 1.2.12

Bubble sort with an "any swap?" flag fixes all of these in one pass. The next pass makes no swaps, so it stops. That's about $O(n)$ work.

=== 1.2.13
Finding the maximum of $n$ numbers always scans every element and makes exactly $n-1$ comparisons, whatever the input. So best, average and worst case are all $\Theta(n)$.

The other options differ: binary search's best case is $O(1)$ but its worst is $O(\lg n)$, and quick sort's average is $n\lg n$ but its worst is $n^2$. Answer: **option B**.

=== 1.2.15
The subsequences are already in order relative to each other, so we only sort each block of $k$ elements.

Any comparison sort of one block needs $\Omega(k\lg k)$ comparisons. The blocks are independent, so the decision-tree lower bound adds up:

$$\frac{n}{k}\cdot\Omega(k\lg k) = \Omega(n\lg k)$$

The answer is **option C**. (Formally, there are $(k!)^{n/k}$ possible outcomes, and $\lg (k!)^{n/k} = \Theta(n\lg k)$.)
