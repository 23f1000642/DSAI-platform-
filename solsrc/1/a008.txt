=== 1.23.9
Floyd–Warshall computes $d^{(k)}_{ij}$, the shortest $i\to j$ path using only intermediate vertices $1..k$, from the $k-1$ table:
$$d^{(k)}_{ij} = \min\left(d^{(k-1)}_{ij},\; d^{(k-1)}_{ik} + d^{(k-1)}_{kj}\right)$$
That's overlapping subproblems with optimal substructure, solved bottom-up: **dynamic programming**, **option C**.

This question's options were garbled in the source. The four orderings offered were:

1. D, B, A, C
2. B, D, A, C
3. C, D, A, B
4. B, C, A, D

The four strategies are:

- **Binary encoding**: a chromosome is a bit string. This is the classic default.
- **Gray coding**: a binary code where adjacent values differ in one bit. It refines binary encoding to avoid "Hamming cliffs".
- **Real-valued encoding**: genes are real numbers, used for continuous parameters.
- **Permutation encoding**: a chromosome is an ordering, used for TSP and scheduling.

There's no universally accepted "sequence" of these, and no official key was released. Treat this item as **not reliably answerable**. Know what each encoding is for, rather than an order.
