=== 2.27.2
Only the leaves that alpha–beta actually reads are shown. Evaluate left to right:

**Left MIN node:**

- 1st MAX child: its MIN children give min(7, 9) = 7, and then min(6, …) ≤ 6. So this MAX node = 7.
- 2nd MAX child: its first MIN child = min(11, 12) = 11 > 7. This MAX node is already ≥ 11, so the rest is pruned.

The left MIN node = min(7, ≥11) = **7**. So α = 7 at the root.

**Right MIN node:**

- 1st MAX child: its MIN children give min(5, …) ≤ 5 and min(4, …) ≤ 4. So this MAX node ≤ 5 < α. The rest of the right subtree is pruned.

The root = **7**. **Option B**.
