=== 12.16.1
a: B
T is stored row-major, so each row (1024 words) is exactly one page. The table spans 17 pages, but memory holds only 16.

For each column j, the inner loop touches pages 0, 1, …, 16 in order. Under LRU with 16 frames, cycling through 17 pages faults on **every** access. The page needed next is always the one that was just evicted.

The total is $1024\times17 = \mathbf{17408}$ faults. **Option B**.

=== 12.19.1
a: C
- (i) `&44` is illegal: you can't take the address of a literal.
- (ii) `int *P = &r;` is legal, assuming r is an int.
- (iii) `int P = &a;` assigns a pointer to an int, which is invalid without a cast.
- (iv) `int P = a;` is legal.

**(ii) and (iv)**, **option C**.
=== 12.19.2
ptr points to arr[2] = 2, and i = 1:

| statement | element | value |
|---|---|---|
| A: ptr[i] | arr[3] | 3 |
| B: ptr[i+1] | arr[4] | 4 |
| C: ptr[−i] | arr[1] | 1 |
| D: ptr[−i+1] | arr[2] | 2 |

Increasing order: **C, D, A, B**, which is choice (2). The A–D options in the PDF are garbled, so pick the one matching (2).
