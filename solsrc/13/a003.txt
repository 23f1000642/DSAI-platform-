=== 13.4.3
**(a) Claim:** in a binary tree, leaves = full nodes + 1. Induct on the height $h$.

- **Base case** ($h = 0$): a single node, with 1 leaf and 0 full nodes. ✔
- **Inductive step**, root $r$:
  - If $r$ has **one** child, the leaves and full nodes are exactly those of the child's subtree, which satisfies the claim by induction.
  - If $r$ has **two** children with $(L_1, F_1)$ and $(L_2, F_2)$, then $L = L_1 + L_2 = (F_1+1) + (F_2+1) = (F_1+F_2+1) + 1 = F + 1$. Here $r$ itself is the extra full node. ✔

**(b) Insert 7, 6, 5, 4, 3, 2, 1 into a min-heap.** Each new key sifts up:
```

       /     \
      4       2
     / \     / \
    7   5   6   3
```
(Array: 1, 4, 2, 7, 5, 6, 3.)
