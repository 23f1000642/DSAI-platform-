=== 13.6.4
- **Height of a binary tree:** the number of edges on the longest path from the root to a leaf. An empty tree has height −1, and a single node has height 0.
- **Height-balanced (AVL) tree:** a binary search tree in which, for **every** node, the heights of the left and right subtrees differ by at most 1. That is, every balance factor is −1, 0 or +1.

=== 13.6.12
```
procedure delete(A, n, i)        { heap stored in A[1..n] }
    A[i] := A[n];  n := n - 1;
    if i > n then return;
    if i > 1 and A[i] < A[i div 2] then     { too small: move up }
        while i > 1 and A[i] < A[i div 2] do
            swap(A[i], A[i div 2]);  i := i div 2
    else                                   { too large: move down }
        loop
            c := smaller child of i (if any);
            if c = none or A[i] <= A[c] then exit;
            swap(A[i], A[c]);  i := c
        end
```
The element moves along a single root-to-leaf path, so the worst case is **$O(\log n)$**.
=== 13.6.13
**Claim:** in a binary tree where every non-leaf node has exactly 2 children, $L = I + 1$. Here $L$ is the number of leaves and $I$ the number of internal nodes.

Use induction on the number of nodes.

- **Base case:** a single node has $L = 1$ and $I = 0$. ✔
- **Inductive step:** the root has subtrees $T_1$ and $T_2$, both full binary trees, so $L_i = I_i + 1$. Then
$$L = L_1 + L_2 = (I_1+1) + (I_2+1) = (I_1 + I_2 + 1) + 1 = I + 1$$
since $I = I_1 + I_2 + 1$ (the root is internal). ✔

=== 13.6.18
**(a)** Let $N(h)$ be the minimum number of nodes. A tree of height $h \ge 1$ has a subtree of height $h-1$, which holds at least $N(h-1)$ nodes. Size balance means the other subtree holds at least $N(h-1) - 1$ nodes. So
$$N(h) \ge 1 + N(h-1) + (N(h-1) - 1) = 2N(h-1)$$
With $N(0) = 1 = 2^0$, induction gives $N(h) \ge 2^h$. ✔

**(b)** Size balance at every node forces all levels except the last to be full. So there are $2^{h-1}$ nodes at distance $h-1$.
