=== 13.17.2
**(a)** $f(x, y)$ appends list $x$ in front of $y$:
$$f([32,16,8],[9,11,12]) = [32,16,8,9,11,12]$$

**(b)** $g(x) = f(g(cdr(x)), [car(x)])$ reverses the list:
$$g([5,1,8,9]) = [9,8,1,5]$$
=== 13.17.3
Represent each list as a chain of cons-cells (a data/sublist field and a next field). Nested parentheses become sublist pointers:

Read as LISP, (((a b) c) d ((e))) is a 3-element list:

1. the sublist ((a b) c)
2. the atom d
3. the sublist ((e))

```
[•|•]──►[d|•]──►[•|/]
 │               │
 ▼               ▼
[•|•]──►[c|/]   [•|/]
 │               │
 ▼               ▼
[a|•]──►[b|/]   [e|/]
```
Each box is [element | next]. "/" means NIL, and a "•" in the element field points to a sublist.
=== 13.17.4
We can't reach the predecessor of node $X$, but we can insert **after** $X$:
```
Y->data = d;
Y->next = X->next;
X->next = Y;
```
That gives $d_1, \dots, d_j, d, \dots, d_n$ in $O(1)$, without touching the header.
