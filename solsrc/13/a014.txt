=== 13.17.9
Name the cells A (p, cell i), B (i+1), C (i+2) and D (i+3).

1. `q := p->next` sets q to B.
2. `p->next := q->next` makes A → C.
3. `q->next := (q->next)->next` makes B → D.
4. `(p->next)->next := q` makes C → B.

Result: A → C → B → D. **It swaps the two nodes after p** (cells i+1 and i+2).
=== 13.17.10
We can't reach p's predecessor, so insert a node **after** p and swap the data:
```
new = allocate();
new->data = p->data;     /* copy p's data into the new node */
new->next = p->next;
p->next  = new;          /* new node now follows p */
p->data  = D;            /* p now holds D, so D sits before the old p->data */
```
This is $O(1)$.

It doesn't work if p must be the address of the original data, e.g. when outside pointers refer to it.
