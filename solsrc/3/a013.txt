=== 3.25.1
a: B
The fragmentation correctness rules are:

- **Completeness:** every data item of the global relation appears in some fragment.
- **Reconstruction:** the global relation can be rebuilt from its fragments.
- **Disjointness:** no item is in two fragments (for horizontal fragmentation).

The question describes **completeness**, **option B**.

With location transparency, the user doesn't need to know *where* data is stored. But without fragmentation transparency, the query still has to name the **fragments**. **Option B**.
=== 3.26.1
