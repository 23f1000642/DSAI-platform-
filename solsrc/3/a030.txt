=== 3.55.10
`FROM r, s` is a cross product. Projecting onto r's columns with DISTINCT gives back the distinct tuples of r, as long as **s isn't empty**. If s is empty, the product is empty.

For the result to equal r exactly, r must also have **no duplicates**. **Option A**.
=== 3.55.11
Treat every comparison with NULL as false, and let x be NULL:

- **A:** x = 5 is false. not(not(x = 5)) is not(not(false)), which is false. Equivalent.
- **B:** x = 5 is false, and x > 4 and x < 6 is false. Equivalent (for integers).
- **C:** x ≠ 5 is **false**, but not(x = 5) = not(false) = **true**. **Not equivalent.**

**Option C**.
=== 3.55.12
**(a)**
```sql
CREATE VIEW TP (acctno, date, amount) AS
SELECT T1.acctno, T1.date, T2.amount
FROM transaction T1, transaction T2
WHERE T1.acctno = T2.acctno
  AND T2.date <= T1.date;
```

**(b)** First compute the balance after each transaction date (the running sum), then take the minimum per account:
```sql
CREATE VIEW V (acctno, date, balance) AS
SELECT acctno, date, SUM(amount)
FROM TP
GROUP BY acctno, date;

SELECT acctno, MIN(balance)
FROM V
GROUP BY acctno;
```
=== 3.55.13
ub references ib with ON DELETE CASCADE. Deleting (x, y) deletes every tuple whose **ub = x**. Each such tuple (z, x) has $x \ge z$. That in turn deletes tuples with ub = z, where z ≤ x, and so on down the chain.

All the cascaded tuples have ub values ≤ x. A deleted tuple (z, w) can therefore have **w < x**. **Option C**.
